2000liad/caliber-relay

האפליקציה קוראת וכותבת ישירות לריפו הפרטי caliber-relay בגיטהאב. כדי שתוכל לגשת אליו, היא צריכה טוקן גישה שאתה יוצר בעצמך. הטוקן נשמר רק בדפדפן הזה, ונשלח רק לגיטהאב.

  1. בגיטהאב: Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token.
  2. Repository access: Only select repositories, ובו רק caliber-relay. תוקף: עד שנה.
  3. Repository permissions: Contents ו-Issues על Read and write. (Metadata: Read נוסף מעצמו.)
  4. העתק את הטוקן והדבק כאן. בכל מכשיר מדביקים פעם אחת.

טוען את יומן המסחר מהריפו…

הכול חי בריפו הפרטי caliber-relay: מקור האמת של הקריאות הוא קבצי ה-jsonl ב-trading/, והמנוע בענן כותב מהם את מה שהמסכים קוראים ב-app/data/. יומן המסחר וגודל התיק נשמרים ב-app/user/, ישירות מהדף. כל בקשה או שאלה נפתחת כ-issue בריפו, והמנוע מתעורר עליה. פגיעה פירושה שהמחיר נגע ביעד בשלב כלשהו עד הדדליין, לפי שיא ושפל תוך-יומי. יום הקריאה עצמו לא נספר. אין כאן פעולת מסחר מול ברוקר, וזה לא ייעוץ השקעות.
